# CarWatch — Telegram Mini App + Bot

Карта меток (машины / опасные ситуации) + SOS для закрытого круга 10–20 человек.

## Что умеет

- **Карта** (OpenStreetMap + Leaflet)
- Долгое нажатие → добавить неподвижную метку
- Тип метки: Опасно / Безопасно / Друг / Обычная
- Произвольная заметка (номер, описание и т.д.)
- Тап по метке → подробности + удаление своих
- **Красная кнопка SOS** → всем друзьям уходит сообщение + геолокация
- Список друзей + их метки на карте + % батареи (когда браузер отдаёт)
- Всё остальное (личные чаты, группы, профили) — нативный Telegram

## Быстрый старт

### 1. Создай бота

1. @BotFather → `/newbot`
2. Сохрани токен
3. `/newapp` → привяжи Mini App (Web App URL потом подставим)

### 2. Подготовка

```bash
cd carwatch-bot
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Отредактируй `.env`:

```
BOT_TOKEN=твой_токен_от_BotFather
ADMIN_IDS=твой_telegram_id
WEBAPP_URL=https://xxxxx.pages.dev          # после деплоя webapp
API_SECRET=любой_длинный_секрет
```

### 3. Запуск API + Бота

Сейчас бот и API в одном файле, но API нужно запускать отдельно (или доработать).

**Самый простой способ для теста:**

Терминал 1 — API:
```bash
cd bot
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Терминал 2 — Бот (нужно немного поправить main.py, чтобы не запускал polling внутри API):
Пока для MVP можно запускать бота отдельно, а API — отдельно.

Я рекомендую на первом этапе:

1. Задеплоить `webapp/` на Cloudflare Pages / Vercel / GitHub Pages
2. Задеплоить бота + FastAPI на Railway / Render / Fly.io
3. В `.env` указать правильные URL

### 4. Mini App

В файле `webapp/index.html` замени две строки:

```js
const API_BASE = "https://твой-api.railway.app";
const API_SECRET = "тот_же_что_в_.env";
```

Потом задеплой папку `webapp` как статику.

В BotFather → Edit App → Web App URL = адрес твоего Mini App.

### 5. Как добавлять друзей

Самый надёжный способ сейчас:
- Попроси друга написать боту `/start`
- Перешли любое его сообщение боту
- Или используй команду добавления (можно доработать)

### 6. SOS

Открываешь карту → жмёшь красную кнопку → подтверждение → всем друзьям уходит:
- Текст с именем
- Ссылка на Google Maps
- Отдельное сообщение с геолокацией

## Что можно улучшить за 1–2 дня

- Красивое добавление друзей через deep-link (`t.me/YourBot?start=add_123456`)
- Уведомления о новых метках
- Фильтр меток по типу
- Кластеризация меток при большом количестве
- Фоновая отправка локации (пока только пока открыта карта)
- Один выделенный SOS-чат (создавать супергруппу и кидать туда)

## Важно

- Для 10–20 человек SQLite + один инстанс более чем достаточно
- OpenStreetMap не требует ключа и бесплатный
- Батарея работает только в поддерживающих браузерах (Chrome/Android в основном)
- Telegram не даёт 100% override silent mode как системный будильник, но уведомление + геолокация работает отлично
